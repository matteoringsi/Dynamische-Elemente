Hinweis zum Einbinden von Google Photos

So können Sie Fotos direkt auf Ihrer Webseite anzeigen:

  1. Öffnen Sie Google Photos und wählen Sie das gewünschte Album oder Foto aus.
  2. Klicken Sie auf Teilen → Link erstellen.
  3. Kopieren Sie den Link.
  4. Fügen Sie den Link in das href des Buttons auf Ihrer Webseite ein.
