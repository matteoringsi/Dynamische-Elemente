Hinweis zum Einbetten von Google Maps

So können Sie eine Karte direkt auf Ihrer Webseite einbinden:

  1. Öffnen Sie Google Maps und suchen Sie die gewünschte Adresse.
  2. Klicken Sie auf Teilen → Karte einbetten.
  3. Kopieren Sie den angezeigten <iframe>-Code.
  4. Fügen Sie diesen Code an der gewünschten Stelle in Ihre HTML-Seite ein.
