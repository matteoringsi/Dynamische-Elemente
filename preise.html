Hinweis zum Einbinden von Google Docs

So können Sie ein Google Doc direkt auf Ihrer Webseite einbetten:

  1. Öffnen Sie das Dokument in Google Docs.
  2. Klicken Sie auf Datei → Im Web veröffentlichen.
  3. Kopieren Sie den bereitgestellten Iframe-Code.
  4. Fügen Sie den Code an der gewünschten Stelle im HTML Ihrer Webseite ein.
